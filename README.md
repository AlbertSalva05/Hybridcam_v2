# Hybrid Cam (deploy)

Escrowed camera marketplace: 16 static pages (HTML, CSS, vanilla JS). This folder is generated by `build/sync-deploy.js` from `hybrid-cam-v2/`. Do not edit it by hand.

## Deploy on Render
1. Delete the old files in the repository first (keep `.git`).
2. Copy the contents of this folder into the repository root.
3. Push with Git (not web drag-and-drop; it caps uploads and can corrupt images).
4. Render: New → Blueprint, or redeploy the existing service; `render.yaml` is picked up automatically. Use "Clear build cache & deploy".
5. Check the live site: open a few pages, then an unknown path (should show the 404 page).

## Contents
- 16 pages, `404.html` (noindex), `robots.txt`, `sitemap.xml`, `site.webmanifest`, `favicon.ico`
- `assets/css`, `assets/js` (minified, content-hashed links), `assets/fonts` (self-hosted woff2)
- `assets/logo` (brand files), `assets/icons` (standard icon set), `assets/og-image.png`
- `render.yaml`: HTML no-cache; CSS, JS and fonts cached a year (immutable); security headers
